Template UI kit

Sections use .section + .stack for rhythm. Cards are calm by default; add .card--interactive only for hover lift. Blocking overlays use .modal; a sheet (no backdrop) keeps context for filters and compact forms. Sign-in is neither: the Auth Kit owns its own dialog.

Buttons
